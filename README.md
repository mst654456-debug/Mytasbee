# تطبيق التسبيح والأذكار — بناء APK عبر GitHub

## الخطوات

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `tasbeeh-apk`).
2. ارفع محتويات هذا المجلد إلى المستودع، بما فيها مجلد `.github` (الملف `build-apk.yml` داخله).
   - إن لم يظهر مجلد `.github` عند الرفع من المتصفح، استخدم Git أو GitHub Desktop.
3. افتح تبويب **Actions** في المستودع، ثم انتظر حتى ينتهي التشغيل **Build APK** (نحو 5 إلى 10 دقائق).
   - يبدأ البناء تلقائياً عند كل رفع، ويمكنك أيضاً تشغيله يدوياً من **Run workflow**.
4. عند نجاح التشغيل، افتح صفحة التشغيل واختر **tasbeeh-debug-apk** من قسم **Artifacts** لتنزيل الملف المضغوط.
5. فك الضغط للحصول على `app-debug.apk`، وانقله إلى الهاتف وثبّته.
   - قد يطلب الهاتف السماح بالتثبيت من مصدر غير معروف لهذا التطبيق.

## ملاحظات

- هذا ملف APK تجريبي للتثبيت الشخصي، وليس نسخة موقّعة لمتجر Google Play.
- التطبيق يعرض الواجهة الموجودة في `www/index.html`. لتعديل المحتوى، عدّل هذا الملف ثم ارفع التغيير.
- معرّف التطبيق `com.tasbeeh.app` في `capacitor.config.json`. يمكنك تغييره إلى معرّف خاص بك.
